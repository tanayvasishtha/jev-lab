jev-lab

Four independent experiments stress-testing TypeSafe's Jev.

Every number on every page traces back to a committed raw response log. Each experiment was preregistered before its data was collected, and the git history proves it.

Build spec Design rationale Source

  • 01 / does Jev know what it doesn't know?

    Calibration audit

    12,697 labeled questions run through Jev's confidence type, checked against ground truth.

    Finding: calibration holds. ECE 0.031, under the 0.05 threshold preregistered.
  • 02 / does asking questions together change the answers?

    Bundle bias

    2,000 questions asked alone, then bundled with 9 unrelated ones across 6,000 paired comparisons.

    Finding: a real, small effect. 3.6% flip rate, flat across position and composition.
  • 03 / does the option's name change what gets picked?

    Label bias

    1,000 routing decisions under four label schemes, identical criteria text, only the key names change.

    Finding: no measurable effect, even under adversarial labeling.
  • 04 / is asking 100 times worth it?

    Ensemble gain

    500 questions asked 100 different ways each, comparing accuracy at ensemble sizes 1 through 100.

    Finding: no, not on this task. Accuracy and calibration both stay flat.

74,697 calls across all four experiments. Total cost: $1.63.
